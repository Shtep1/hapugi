# Хапуги

Карточная игра про жадных героев. Сервер на Node.js отдаёт игру и держит комнаты для сетевой игры до 4 игроков (пустые места занимают боты).

## Запуск у себя

```
npm install
npm start
```

Игра откроется на http://localhost:3000

## Деплой на Render

1. Залей эту папку в репозиторий на GitHub.
2. На render.com: New → Web Service → выбери репозиторий.
3. Runtime: Node. Build Command: `npm install`. Start Command: `npm start`. Instance Type: Free.
4. Нажми Deploy. Через пару минут игра будет по адресу вида `https://hapugi.onrender.com`.

Бесплатный сервер на Render засыпает после 15 минут без игроков, первое открытие после этого грузится около минуты.

## Как играть с друзьями

Открой сайт, нажми «Создать комнату», скинь друзьям ссылку и код. Они вводят код и жмут «Войти по коду», ты жмёшь «Начать игру».
